# 撕纸拼贴风个人主页

基于「参考网站」截图还原的撕纸拼贴（torn-paper collage）风格个人主页，内容已按「个人内容 / 个人信息与经历档案」及「个人简历.pdf」填充。

## 页面

| 文件 | 页面 | 内容 |
| --- | --- | --- |
| `index.html` | 关于我 | 右侧生活照抠像主图（青色描边 + 空隙，无相框、无证件照）；定位、简介、「查看简历 / 联系我」、求职意向卡、荣誉奖励（无贴纸） |
| `education.html` | 教育背景 | 重庆工商大学（产业经济学·硕士）、赣南师范大学科技学院（国际经济与贸易·本科）；本页字体大一号 |
| `practice.html` | 实践经历 | 云南白药驻店销售、研究生助教、成渝论坛会务；核心职责四卡 + 核心成果 |
| `projects.html` | 项目经历 | 重庆市研究生科研创新项目、国家社会科学基金项目、重庆市教委人文社科重点项目 |
| `skills.html` | 技能特征 | 研究与分析 / 数据分析与工具（GPT · Gemini · opencode）/ 沟通表达 / 项目管理 + 证书与资格 |

## 素材（assets/）

- `个人简历.pdf`：随站点分发，「查看简历」按钮直接打开
- `生活照_抠像_web.png`：首页主图（生活照 AI 抠像，青色描边与照片间留有空隙）
- `证件照.jpg`、`生活照1.jpg`、`生活照2.jpg`、奖学金证明、主持项目证明（备用素材，页面未直接引用）

## 样式说明

- 全部贴纸文字使用正楷（KaiTi），文字不参与撕裂滤镜，保持清晰
- 撕纸边缘、和纸胶带、便利贴等拼贴元素保留

## 使用

直接浏览器打开任意 `*.html` 即可；`预览/` 为各页渲染截图。整站文件夹发给任何人，「查看简历」都可直接打开 PDF。
